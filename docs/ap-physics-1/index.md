## 💡 Core Principles for AP Physics Success

- **Algebraic Derivations Before Numbers:** AP Physics 1 Free-Response Questions predominantly test symbolic manipulation rather than arithmetic computation.
- **Graph Interpretation:**
    - **Position-Time ($x$-$t$):** Slope is velocity ($v = \frac{dx}{dt}$).
    - **Velocity-Time ($v$-$t$):** Slope is acceleration ($a = \frac{dv}{dt}$); Area under curve is displacement ($\Delta x = \int v\,dt$).
    - **Acceleration-Time ($a$-$t$):** Area under curve is change in velocity ($\Delta v = \int a\,dt$).
    - **Force-Position ($F$-$x$):** Area under curve is work done ($W = \int F\,dx$).
    - **Force-Time ($F$-$t$):** Area under curve is impulse ($\vec{J} = \Delta\vec{p}$).
- **Sign Conventions:** Establish a coordinate system at the beginning of every problem and adhere to it strictly.
