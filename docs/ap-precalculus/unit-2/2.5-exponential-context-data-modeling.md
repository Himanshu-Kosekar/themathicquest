## 📖 Core Concepts & Learning Objectives

- **Discrete Compounding:** $A(t) = P\left(1 + \dfrac{r}{n}\right)^{nt}$ where $P$ is principal, $r$ is annual rate, $n$ is compoundings per year.
- **Continuous Compounding & Natural Base $e$:** $A(t) = P e^{rt}$.
- **Half-Life Modeling:** $N(t) = N_0 \left(\dfrac{1}{2}\right)^{t / t_{1/2}} = N_0 e^{-kt}$ with $k = \dfrac{\ln 2}{t_{1/2}}$.
- **Doubling Time:** $P(t) = P_0 (2)^{t / t_d}$.

## 📐 Essential Formulas & Definitions

**Discrete Compound Interest:**

$$A(t) = P\left(1 + \frac{r}{n}\right)^{nt}$$

**Continuous Compounding Model:**

$$A(t) = P e^{r t}$$

!!! tip "AP Exam Tip"
    Always convert interest percentages into decimal form before substituting into formulas (e.g., $4.5\% = 0.045$).
