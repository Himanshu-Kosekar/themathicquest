## 📖 Core Concepts & Learning Objectives

- **Invertibility Condition:** A function has an inverse function if and only if it is one-to-one (passes the Horizontal Line Test).
- **Algebraic Method:** Set $y = f(x)$, swap $x$ and $y$, and solve for $y = f^{-1}(x)$.
- **Graphical Reflection:** The graph of $f^{-1}(x)$ is the reflection of $f(x)$ across the line $y = x$. If $(a, b)$ is on $f$, then $(b, a)$ is on $f^{-1}$.
- **Inverse Verification:** $f(f^{-1}(x)) = x$ for all $x$ in domain of $f^{-1}$, and $f^{-1}(f(x)) = x$ for all $x$ in domain of $f$.

---

## 📐 Essential Formulas & Definitions

**Inverse Function Composition Identity:**

$$f\big(f^{-1}(x)\big) = x \quad \text{and} \quad f^{-1}\big(f(x)\big) = x$$

!!! tip "AP Exam Tip"
    The symbol $f^{-1}(x)$ means the inverse function, NOT the reciprocal $\frac{1}{f(x)}$! The reciprocal is denoted as $[f(x)]^{-1}$.
