## Core Concepts & Learning Objectives

- **Linear Change:** Over equal input intervals $\Delta x$, the output changes by a constant difference $\Delta y = m \Delta x$.
- **Exponential Change:** Over equal input intervals $\Delta x$, the output changes by a constant ratio / factor $\dfrac{f(x + \Delta x)}{f(x)} = b^{\Delta x}$.
- **Data Identification:** Test table outputs: if $y_{k+1} - y_k = \text{const} \implies$ linear; if $y_{k+1} / y_k = \text{const} \implies$ exponential.

---

## Essential Formulas & Definitions

**Exponential Constant Ratio Property:**

$$\frac{f(x + c)}{f(x)} = b^c = \text{constant for any fixed } c$$

!!! tip "AP Exam Tip"
    If inputs are not spaced by $1$, compute the base using $b = \left(\frac{y_2}{y_1}\right)^{1 / (x_2 - x_1)}$.
